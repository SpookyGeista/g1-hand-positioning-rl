# G1 Hand Positioning RL

RL tasks and deployment extensions for G1 hand positioning.

- Task variants with hand-position commands and termination conditions.
- PPO configurations and an additional deployment state.
- CSV playback and hand-pose calculation from joint measurements.

## Usage

The directory structure follows the target paths in Unitree RL Lab.
Changes to existing files are in `patches/`.
The base revision and application instructions are recorded in `UPSTREAM.json`.
