# G1 Hand Positioning RL

RL tasks and deployment extensions for G1 hand positioning: hand-position commands, task termination conditions, PPO configurations, CSV playback, and hand-pose calculation from joint measurements.

## Initialize the integration

Use an existing Isaac Sim 5.1 / Isaac Lab environment. This repository is an overlay for the Unitree RL Lab revision in `UPSTREAM.json`.

```bash
git clone https://github.com/SpookyGeista/g1-hand-positioning-rl.git
git clone https://github.com/unitreerobotics/unitree_rl_lab.git
cd unitree_rl_lab
git checkout 4960b84732b0c2ec593dccbfe963fda1bcd7b1e3
git apply --check ../g1-hand-positioning-rl/patches/local-code.patch
git apply ../g1-hand-positioning-rl/patches/local-code.patch
cp -R ../g1-hand-positioning-rl/source/. source/
cp -R ../g1-hand-positioning-rl/scripts/. scripts/
cp -R ../g1-hand-positioning-rl/deploy/. deploy/
```

Activate the Isaac Lab environment, then install the tasks:

```bash
./unitree_rl_lab.sh -i
```

Set `UNITREE_ROS_DIR` and, if using USD assets, `UNITREE_MODEL_DIR` in `source/unitree_rl_lab/unitree_rl_lab/assets/robots/unitree.py`. Check that the G1 URDF and mesh files referenced by the selected configuration exist. The overlay contains local machine paths that must be adapted.

## Verify and start training

```bash
python scripts/list_envs.py
python scripts/rsl_rl/train.py \
  --task Unitree-G1-29dof-HandPosition --headless
```

The alternate task is `Unitree-G1-29dof-HandPosition-V2`. Training requires the simulator, configured robot assets, and a compatible NVIDIA GPU. Checkpoints and logs are generated by the upstream trainer. Simulation setup and hardware deployment are separate steps.
